Using pipx or a managed Python installation

Pipx is optional: pipx install . installs the CLI in an environment it manages automatically. If pip reports externally-managed-environment, that Python distribution requires an isolated install. See installation alternatives.

Account CLI commands

Uses your existing ChatGPT sign-in. Run dots auth if you are not signed in, or dots check to test the connection. Catalog reads are verified; creation is still unverified. The account API is experimental.

LIST ACCOUNT DOTS
dots list
CREATE A DOT
dots create research
SELECT PRIMARY DOT
dots use research
INSPECT PROFILE
dots show research
READ ACTIVITY
dots activity research
READ TASK HISTORY
dots tasks research
INSPECT ONE TASK
dots tasks research --task TASK_ID
REQUEST RUNTIME PAUSE
dots pause research
REQUEST RUNTIME RESUME
dots resume research
CREATE OR RECOVER MESSAGING ROOM
dots room research

Every command accepts --json. Names must be unique; IDs also work. Omit the target to use the only or primary Dot. Creation, room repair, and selection are separate actions. If catalog lookup is broken, target a known ID with dots show DOT_ID --by-id; the same flag works for activity, tasks, use, room, pause, and resume. dots create NAME --first or --additional skips the creation catalog lookup. An uncertain write is never automatically retried.

Launcher actions and limits

Use dots doctor for local checks, dots prompt local to print a task, and dots run --preset local to copy it and open ChatGPT. These local launch commands do not submit tasks. Account commands use the separate experimental API integration; see its authentication limits above. See LAUNCHER.md for the full command reference.

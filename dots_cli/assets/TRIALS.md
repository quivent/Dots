# Dots interaction trials

Reusable trial template. The guide saves actual notes in the private runtime file `dots-trials.md`; agent results belong in local `FIRST-RESULT.md`. This tracked template contains no personal observations.

## First trials

- Account access: dots appears and a named dot can be opened.
- Text: send FIRST-MESSAGE.md; check its claims about available tools.
- Local task: connect the Mac, request FIRST-RESULT.md, and open the resulting file.
- Continuity: return later and ask it to continue from the recorded result.
- Optional voice or iPhone shortcut: initiate a conversation and record whether it reaches the same dot.

The useful comparison is actual completion, required intervention and continuity. Timings apply only to the recorded task and channel. No synthetic score or untested success belongs here.
